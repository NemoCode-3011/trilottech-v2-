# Trilot Technologies

Trilot Technologies builds digital experiences for businesses, from websites that present a brand clearly to web products that help people get things done.

**Website:** https://trilottechnologies.vercel.app/

## What this project is

This repository contains the Trilot Technologies website, built to present the company, communicate its services, and give prospective clients a way to learn more and make enquiries.

## Tech stack

- React
- TypeScript
- Vite

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Useful scripts:

```bash
npm run build
npm run lint
```

## Development

Keep the website's messaging, service descriptions, contact details, and visual identity consistent with the Trilot Technologies brand. Before deploying changes, run the available build and lint scripts.
